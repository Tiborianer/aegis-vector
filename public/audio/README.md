# Optional soundtrack files

Place the five ElevenLabs exports in this folder using these exact names:

- `menu.mp3`
- `mission.mp3`
- `boss.mp3`
- `victory.mp3`
- `defeat.mp3`

WAV source files are preferable for editing, but the browser build loads MP3 files for broad hosting compatibility. When a file is absent, Aegis Vector falls back to its synthesized soundtrack.
