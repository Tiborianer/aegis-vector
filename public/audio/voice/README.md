# Optional radio voice files

Add MP3 recordings with these exact names: `shield-down.mp3`, `hull-critical.mp3`, `shield-restored.mp3`, `emp-ready.mp3`, `arc-upgraded.mp3`, `nova-upgraded.mp3`, `lance-upgraded.mp3`, `wing-upgraded.mp3`, `ion-upgraded.mp3`, and `aegis-upgraded.mp3`.

The game always presents the matching subtitle. If a recording is absent, it continues silently without affecting music or SFX and reports `RADIO VOICES MISSING // SUBTITLES ONLY` in the Audio panel.
